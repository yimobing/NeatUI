Mock.js 离线语法示例文档

备份来源：http://mockjs.com/examples.html
本地打开即可查阅所有模板语法、占位符示例；可复制代码到控制台测试 Mock.mock()
💡 使用小技巧：打开浏览器F12控制台，直接复制示例代码执行 Mock.mock({...}) 即可看输出结果。
离线备份，防止官网 mockjs.com 失效；CDN使用bootcdn公共库。

数据模板定义 Data Template

String 字符串

// 'name|min-max': string
    Mock.mock({
    "string|1-10": "★"
    })
Result { "string": "★★★★★★★★" }
// 'name|count': string
    Mock.mock({
    "string|3": "★★★"
    })
Result { "string": "★★★★★★★★★" }

Path 路径引用

// Absolute Path
    Mock.mock({
    "foo": "Hello",
    "nested": {
    "a": {
    "b": {
    "c": "Mock.js"
    }
    }
    },
    "absolutePath": "@/foo @/nested/a/b/c"
    })
Result { "foo": "Hello", "nested": { "a": { "b": { "c": "Mock.js" } } }, "absolutePath": "Hello Mock.js" }
// Relative Path
    Mock.mock({
    "foo": "Hello",
    "nested": {
    "a": {
    "b": {
    "c": "Mock.js"
    }
    }
    },
    "relativePath": {
    "a": {
    "b": {
    "c": "@../../../foo @../../../nested/a/b/c"
    }
    }
    }
    })
Result { "foo": "Hello", "nested": { "a": { "b": { "c": "Mock.js" } } }, "relativePath": { "a": { "b": { "c": "Hello Mock.js" } } } }
