让Mock支持 $.ajax GET 请求使用data参数传递数据 
            Mock模拟数据：
            Mock.mock(url, type, object or function);  拦截ajax请求并返回数据
            常见的Mock模拟数据写法有2个：
            Mock.mock(url, type, {});
            Mock.mock(url, type, function(v){ return Mock.mock({})});

默认的Mock.js，type 请求方式值为 get 或 post。若 ajax 有发送到服务器的数据(即有 data 参数)，则 type必须为post而不能为get，否则拦截失效(模拟数据失败) ！

引入 mock-ajax-get.js 后，即使请求方式值为type = 'get', ajax也可传递 data 参数，mock 也能正常拦截，不会失败。
